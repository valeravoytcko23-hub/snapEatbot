# snapEatbot

Telegram-бот и веб-интерфейс (включая админ-панель) с деплоем на Render.

## Структура проекта

- `main.py` — точка входа приложения и основная логика бота/сервера.
- `static/index.html` — клиентская веб-страница.
- `static/admin.html` — страница администратора.
- `render.yaml` — конфигурация сервиса для деплоя на Render.
- `requirements.txt` — список Python-зависимостей.

## Локальный запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/valeravoytcko2/snapEatbot.git
   cd snapEatbot
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Linux / macOS
   # .venv\Scripts\activate   # Windows
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Задайте переменные окружения и запустите приложение:
   ```bash
   python main.py
   ```

## Переменные окружения

Укажите нужные переменные в настройках окружения или в `render.yaml` (секреты задавайте в панели Render, а не в коде):

- `BOT_TOKEN` — токен Telegram-бота (при необходимости).
- Другие ключи API / настройки подключения к БД — заполните по вашему проекту.

## Деплой на Render

Репозиторий содержит `render.yaml` для настройки сборки и запуска сервиса на Render. Подключите репозиторий в кабинете Render, проверьте переменные окружения и выполните деплой.
