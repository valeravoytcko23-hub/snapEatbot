# snapEatbot

Telegram Mini App и бот **SnapEat** для учёта калорий, КБЖУ, воды, веса, генерации рационов и администрирования на FastAPI + aiogram + PostgreSQL.

## Состав архива

- `main.py` — FastAPI-сервер, Telegram-бот (webhook), расчёт КБЖУ, ИИ-анализ еды/этикеток/рационов, оплата (Telegram Stars и ЮKassa), админ-API и логирование.
- `static/index.html` — клиентский интерфейс Mini App (дневник, ИИ-рацион, прогресс и динамика веса, профиль, тарифы и поддержка).
- `static/admin.html` — панель администратора (сводка, управление пользователями/подписками/кредитами, обращения поддержки, история оплат и логи).
- `render.yaml` — конфигурация сервиса для Render.
- `requirements.txt` — зависимости Python.
- `.gitignore` — правила игнорирования файлов для Git.
- `legacy_reference/` — исходные версии файлов из предыдущих шагов (`main_3.py`, `index_3.html`, `admin_2.html`, `render_2.yaml`, `requirements_2.txt`, `README_prev.md`) для сверки без путаницы.

## Проверки целостности и защиты от ошибок

1. **Синтаксис и структура**: проверен AST-разбор `main.py`, валидность `render.yaml` и `requirements.txt`, целостность HTML/JS-структуры `static/index.html` и `static/admin.html`.
2. **Безопасность и авторизация**: проверка Telegram `initData` по HMAC-SHA256 с контролем свежести `auth_date`, проверка прав администратора (`ADMIN_IDS`), сравнение секрета вебхука через `hmac.compare_digest`, маскирование секретов в логах (`_err`).
3. **Устойчивость к сбоям и БД**: пул соединений `psycopg_pool` с автоповтором при разрыве соединения и откатом транзакций при ошибках, атомарное списание/возврат квот ИИ и билетов рациона при ошибках провайдера, единый обработчик неперехваченных исключений на сервере и таймауты/обработка ошибок на клиенте.
